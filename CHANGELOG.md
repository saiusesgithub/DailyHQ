# Changelog

All notable changes to DailyHQ are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-01

### Added

- Responsive Windows and Android application shell with light and dark themes.
- Personal Firebase device connection and user-scoped Firestore synchronization.
- Dashboard, Daily Tasks, To-do List, Thoughts, Projects, LinkedIn Posts, Journal, and Learning modules.
- Daily and monthly recurring tasks, subtasks, priorities, deadlines, and task carry-over workflows.
- LinkedIn post planning with list and calendar views.
- Windows installer and global quick-capture keyboard shortcuts.
- Automated Android and Windows builds.
